# 健康数据 Skill

## 能力定义

健康数据 Skill 是运动健康 Agent 的"感官系统"。它负责**整合来自多个来源的健康数据，将碎片化的数字转化为有意义的洞察**，并在发现异常时主动预警。

用户不需要成为数据分析师才能从自己的健康数据中获益——这正是这个 Skill 存在的意义。

## 核心分析能力

### 1. 睡眠分析

睡眠是影响运动表现和健康恢复的关键因素，是优先级最高的分析维度。

```
睡眠质量评分算法（综合以下维度）：
- 总睡眠时长（目标：7-9小时）          权重：30%
- 深度睡眠比例（目标：15-20%）         权重：25%
- 快速眼动（REM）比例（目标：20-25%）  权重：25%
- 入睡时间一致性（波动<30分钟为佳）    权重：20%
```

**睡眠数据影响链：**
```
睡眠评分 < 60
    ├── 通知训练计划 Skill → 降低当日训练强度
    ├── 通知目标追踪 Skill → 调整当日目标期望值
    └── 主动向用户发起对话 → 询问原因 + 提供改善建议
```

### 2. 心率变异性（HRV）分析

HRV 是衡量自主神经系统状态的核心指标，能反映身体的恢复能力和压力水平。

<Tabs>
  <Tab title="HRV 趋势解读">
    ```
    用户：我的 HRV 最近一周都很低，是什么原因？

    Agent：我分析了你过去7天的数据，给你一些可能的解释：

           📉 你的 HRV 趋势
           上周均值：62ms → 本周均值：48ms（下降22%）

           可能的影响因素：
           ① 睡眠质量下降 — 本周平均睡眠时长比上周少55分钟
           ② 训练负荷增加 — 本周总训练量是上周的1.4倍
           ③ 周三记录显示你报告了"工作压力大"

           这几个因素叠加，HRV 下降是正常的生理反应。

           建议：
           • 本周降低训练强度，以有氧为主
           • 尝试睡前10分钟的呼吸放松练习
           • 如果压力持续，考虑安排一个积极休息日

           一般情况下，适当恢复后HRV会在3-5天内回升。
    ```
  </Tab>
  <Tab title="HRV 指导训练">
    HRV 可以直接指导当日训练决策：

    | HRV 状态 | 相对基准线 | 训练建议 |
    |---------|-----------|---------|
    | 优秀 | > +10% | 可以进行高强度训练 |
    | 正常 | ±10% | 按计划正常训练 |
    | 偏低 | -10% ~ -20% | 降低强度，专注技术 |
    | 很低 | < -20% | 建议休息或轻度有氧 |
  </Tab>
</Tabs>

### 3. 体重与体成分追踪

体重数据存在高频波动的特点，需要教育用户正确解读，避免情绪化反应。

```
体重波动的正确解读：

日内波动：1-3kg 属于正常（水分、食物重量）
日间波动：±0.5kg 属于正常（不代表真实脂肪变化）

真实体脂变化需要：
- 7-10天滑动平均才能看出真实趋势
- 结合饮食热量盈亏数据解读
- 体重+体围+照片记录多维度评估

[设计要点] Agent 不应对单日体重异常过度反应：
❌ "今天体重涨了0.8公斤，你可能需要调整饮食..."
✅ "今天体重有所浮动，这很正常。我们看7天趋势更准确——
   目前你的7天均值比上周下降了0.3kg，保持在预期减脂速度内。"
```

## 数据洞察的呈现设计

### 洞察卡片规范

健康数据的呈现需要做到：简单、有意义、可行动。

```
📊 本周健康洞察

✨ 亮点
• 静息心率比上月降低了 4bpm — 心肺功能在改善
• 深度睡眠时间增加 23% — 身体恢复能力提升

⚠️ 需要关注
• 周三至周五连续3天步数 < 3,000步 — 久坐时间偏长

💡 一个建议
每工作90分钟，起身走动3分钟。设置一个提醒？
[是，帮我设置] [我自己记得]
```

**呈现原则：**
1. 先说好消息，再说需要改进的
2. 每次洞察只提一个核心行动建议
3. 用比较（和上周/上月对比）而非绝对数字
4. 异常数据不引发恐慌，而是提供解释框架

### 异常预警分级

| 级别 | 触发条件 | 呈现方式 | 建议行动 |
|-----|---------|---------|---------|
| **信息** | 轻微偏差，可能有合理解释 | 在下次打开时展示 | 提供解释和轻量建议 |
| **注意** | 连续多日异常，需要关注 | 主动推送，措辞平和 | 调整计划 + 追踪观察 |
| **提醒** | 可能影响健康的信号 | 主动推送，明确告知 | 建议就医或咨询专业人士 |

<Warning>
  健康数据 Skill 不具备医疗诊断能力。当数据出现可能提示健康问题的异常时（如持续异常心率、胸痛报告等），应立即引导用户寻求专业医疗建议，不能自行给出诊断。
</Warning>
