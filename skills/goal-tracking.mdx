# 目标追踪 Skill

## 能力定义

目标追踪 Skill 是贯穿用户整个健康旅程的**"导航系统"**。它帮助用户将模糊的健康愿望转化为具体可执行的目标，持续追踪进度，并在关键时刻提供情感支持和动力。

这个 Skill 的核心不只是数据追踪，更是**行为心理学的实践**——理解什么时候用户需要推动，什么时候需要理解，什么时候需要庆祝。

## 目标的全生命周期

```
模糊愿望 → 具体目标 → 阶段计划 → 日常执行 → 进度追踪 → 庆祝/调整 → 新目标
    ↑                                                            │
    └────────────────────────────────────────────────────────────┘
                        持续循环
```

## 目标设定：从愿望到计划

### 目标澄清对话框架

用户最初的目标往往是模糊的，需要通过结构化对话将其转化为可执行的具体目标：

<Tabs>
  <Tab title="SMART 化过程">
    ```
    用户：我想变瘦

    Agent：很好的目标！让我们让它变得更具体，这样我们才能
           真正帮你实现它。

           你目前大概是多少斤？希望达到多少斤？
           （如果不方便说体重，也可以聊聊你想要的状态）

    用户：现在65公斤，想到58公斤

    Agent：7公斤的目标，非常合理！

           减脂速度太快对身体不好，健康的减脂速度是
           每月 0.5-1 公斤。按这个节奏：

           📅 保守估计：7-14个月
           📅 积极估计：7个月（需要更严格的饮食控制）

           你希望在什么时间段内实现这个目标？
           A. 3-4个月（激进，需要严格控制）
           B. 6个月（适中，可持续）
           C. 1年（稳健，生活方式导向）
           D. 没有明确时间，慢慢来

    用户：B，6个月

    Agent：6个月，减重7公斤 — 很清晰的目标！

           我为你拆解了一下：
           月目标：约减重 1.2 公斤
           周目标：约减重 0.3 公斤
           日热量缺口：约 250-300 大卡

           要基于这个目标开始制定你的训练和饮食计划吗？
    ```

### 多目标管理

用户可能同时有多个健康目标，需要明确优先级和潜在冲突：

```
目标冲突检测示例：

用户设定：
  目标A：3个月内增肌5公斤
  目标B：同期减脂8公斤

Agent 的处理：
  "这两个目标有一些冲突——增肌需要热量盈余，
   而减脂需要热量缺口。同时实现这两个目标会很困难。

   以下是三个更现实的方案：
   
   方案一：先减脂后增肌（分阶段）
   方案二：体型重组（保持体重，同时减脂增肌，速度慢但均衡）
   方案三：先聚焦增肌，接受体重有所增加
   
   你倾向哪个方向？"
```

## 进度追踪的设计

### 追踪频率策略

不同类型的目标需要不同的追踪节奏：

| 目标类型 | 追踪频率 | 追踪指标 | 呈现方式 |
|---------|---------|---------|---------|
| 体重目标 | 周均值 | 7日移动平均体重 | 趋势折线图 |
| 习惯养成 | 每日 | 连续完成天数 | 打卡日历 |
| 体能目标 | 双周测评 | 特定动作表现 | 进度条 + 对比 |
| 综合健康 | 月度 | 复合健康评分 | 雷达图 |

### 进度呈现设计规范

```
目标进度卡片（标准格式）

[目标名称]
减重至 58kg（6个月计划）

进度：第2个月 / 共6个月
    [===========          ] 33%

实际进展：
  开始：65.0 kg
  当前：63.5 kg（-1.5 kg）
  目标：58.0 kg（还差 5.5 kg）

本月节奏：-0.8 kg（目标 -1.2 kg）
状态：⚠️ 略低于计划，但在可调整范围内

[查看分析] [调整目标]
```

## 激励机制设计

### 激励类型矩阵

激励不是单一的"鼓励话语"，而是根据不同情境选择最合适的激励方式：

<Columns cols={2}>
  <Card title="成就庆祝" icon="trophy">
    **触发场景：** 达成里程碑、突破个人记录、连续完成打卡

    **设计原则：**
    - 庆祝要及时（发生时立即触发，不要延迟）
    - 庆祝要具体（说明为什么这个里程碑有意义）
    - 庆祝要有仪式感（不只是一句话，要有视觉反馈）
  </Card>
  <Card title="困难支持" icon="hand-holding-heart">
    **触发场景：** 连续未完成训练、目标进度落后、用户表达沮丧

    **设计原则：**
    - 先共情，再分析，再建议
    - 不责备，不说"你应该..."
    - 提供具体的、小步骤的解决方案
  </Card>
  <Card title="主动鼓励" icon="fire">
    **触发场景：** 平台期、用户长时间未互动、重要时间节点

    **设计原则：**
    - 基于用户数据给出个性化鼓励
    - 避免通用、空洞的鼓励话语
    - 配合行动引导，不只是"加油"
  </Card>
  <Card title="进步提示" icon="chart-line">
    **触发场景：** 周期性复盘、用户主动查询

    **设计原则：**
    - 对比过去让进步可见
    - 即使绝对进展不明显，也要找到相对进步点
    - 把小进步和大目标连接起来
  </Card>
</Columns>

### 里程碑庆祝设计

```
里程碑庆祝对话示例（完成首次10公里跑）：

Agent（即时推送）：
  🎉 你刚刚完成了人生第一个10公里！

  距离你6周前告诉我"我从来没跑完过5公里"，
  你今天跑了10公里。

  用时：1小时02分钟
  平均配速：6'12"/km
  心率区间：主要在有氧区（很稳健的跑法！）

  你知道吗？能以这个配速稳定完成10km，
  你已经超过了大多数刚开始跑步的人。

  接下来，要不要聊聊你的下一个目标？
  也许是半程马拉松？😊
```

**里程碑庆祝的关键设计点：**
1. 将数据转化为"意义"，不只是数字
2. 对比起点，让进步感更强烈
3. 自然过渡到下一个目标，维持动力

### 平台期应对策略

平台期是用户流失的高风险阶段，需要专门的支持策略：

<AccordionGroup>
  <Accordion title="体重平台期">
    ```
    检测：连续2周体重无变化（±0.3kg范围内）
    
    Agent 的介入：
    
    "我注意到你的体重在过去两周比较稳定，这其实是很常见的——
     这叫做减重平台期，几乎每个减重的人都会遇到。
     
     这不是失败，这是身体在适应。这里有几个可能的突破方向：
     
     ① 检查是否有热量摄入悄悄增加（比如份量渐渐变大）
     ② 尝试调整运动方式（给肌肉新刺激）
     ③ 检查睡眠和压力状态（皮质醇影响减脂）
     ④ 确保蛋白质摄入达标（保护肌肉）
     
     我们来看看你的数据，找找可能的原因？"
    ```
  </Accordion>
  <Accordion title="习惯养成平台期">
    当用户已经养成习惯后，缺乏新鲜感导致的懈怠：
    - 引入新的训练变化（新动作、新场景）
    - 设置新的短期挑战（"这周尝试晨跑挑战？"）
    - 展示累积成就，强化已有进步感
  </Accordion>
</AccordionGroup>

## 目标调整机制

目标不是一成不变的，Agent 需要在合适时机主动提出目标调整：

```
目标调整触发条件：

主动调整建议（Agent 发起）：
  - 连续4周进度落后50%以上 → 建议放宽目标
  - 连续4周超额完成150%以上 → 建议提升目标
  - 用户生活发生重大变化（受伤/搬家/怀孕等）

用户发起调整：
  - 随时可通过对话表达想要调整目标
  - Agent 不应质疑用户的调整决定，而是帮助制定新计划
```

<Note>
  目标下调不是失败，而是理性调整。Agent 应该以正面积极的语气帮助用户重新制定可实现的目标，而不是表达失望或发出警告。
</Note>
