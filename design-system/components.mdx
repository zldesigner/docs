## Hero Coach Card（英雄教练卡）

产品中最核心的视觉元素，承载 Agent 的主动建议，是**暗色渐变背景 + 白色文字 + 半透明选项行**的组合。

### 结构

```
┌─────────────────────────────────────────┐  ← border rgba(216,249,255,0.18)
│ ✦ 告诉我一个方向          [渐变文字标签]  │
│                                          │
│  今天想让哪件事变好一点？  [章节标题 26px]│
│                                          │
│  描述文字                [正文 15px]     │
│                                          │
│ ┌──────────────────────────────────────┐ │  ← White/5 bg + White/20 border
│ │ 🔴 减脂               →             │ │  ← 分类按钮行
│ └──────────────────────────────────────┘ │
│ ┌──────────────────────────────────────┐ │
│ │ 💜 改善睡眠           →             │ │
│ └──────────────────────────────────────┘ │
│ ┌──────────────────────────────────────┐ │
│ │ 💚 动起来             →             │ │
│ └──────────────────────────────────────┘ │
└─────────────────────────────────────────┘
```

### 规格

| 属性 | 数值 |
|---|---|
| 宽度 | 370px（撑满屏幕 - 16×2 内边距） |
| 内边距 | 24px |
| 组件间距 | 16px |
| 圆角 | 32px |
| 背景 | 渐变 270deg: #FF6A4B → #6D51F4 → #0D9EAA + 深色 radial 叠加 |
| 边框 | 1px solid rgba(216,249,255,0.18) |

### 渐变标签（✦ 告诉我一个方向）

- 字号：13px / Medium
- 颜色：品牌渐变 clip-text（cyan → purple → orange-red）
- 前缀：`✦`（装饰符号，非 emoji）

### 分类选项行

```css
/* 每一行按钮 */
background: rgba(255,255,255,0.05);
border: 0.5px solid rgba(255,255,255,0.20);
border-radius: 32px;
padding: 12px 12px 12px 12px;

/* 图标背景圆形 */
width: 28px; height: 28px;
border-radius: 28px;
/* 颜色跟随分类 */

/* 文字 */
font: Bold 20px PingFang VF;
color: white;
```

## 分类色彩规则

每个健康方向有固定的品牌色，在图标背景、活跃状态、图表中保持一致。

| 分类 | 颜色 | 色值 |
|---|---|---|
| 减脂 / 消耗 | 橙红 | `#FF6A4B` |
| 睡眠 | 紫色 | `#6E50FF` |
| 运动 / 动起来 | 青绿 | `#00A7A0` |
| 饮食（待定） | — | 参考 Color/Lime |

## Timeline（时间轴）

用于展示今日已发生与计划中的事件流，是主页的主要内容区域。

### 节点结构

```
○  现在，已完成 1 次运动      ← 灰色圆形图标 + 小字状态
│
●  8:15                       ← 青色实心图标（已完成事件）
   完成户外跑步 5.20 公里      ← 卡片标题 20px Bold
│
○  7:45                       ← 白色圆形图标（普通事件）
   早晨起床
```

### 节点规格

| 状态 | 背景 | 边框 |
|---|---|---|
| 普通 / 未来 | `#FFFFFF` | `1px solid #DDE5DE` |
| 已完成 / 激活 | `#00A7A0` | 无 |
| 系统节点 | `#FFFFFF` | `1px solid #DDE5DE` |

```css
/* 节点图标容器 */
width: 48px; height: 56px;
border-radius: 48px;  /* 全圆 */

/* 连接线 */
width: 1px; height: 24px;
/* 颜色与相邻节点状态相关 */

/* 时间文字 */
font: Medium 12px; color: rgba(0,0,0,0.6);

/* 事件标题 */
font: Bold 20px; color: black;
```

### 筛选 Segment

位于 Timeline 上方，按类型过滤事件。

```css
/* 容器 */
background: rgba(0,0,0,0.05);
border-radius: 32px;
padding: 4px;

/* 激活项 */
background: #FFFFFF;
border-radius: 24px;
padding: 6px 16px;
font: Bold 14px;

/* 非激活项 */
background: transparent;
padding: 6px 16px;
font: Regular 14px;
```

## Bottom Dock（底部输入 Dock）

固定在屏幕底部，承载对话入口与技能触发。

### 布局

```
┌─────────────────────────────────────────────────────┐
│ [技能]  [有任何问题可以直接对我说         ] [+] [🎙] │
└─────────────────────────────────────────────────────┘
```

### 技能按钮

```css
background: #111713;
border-radius: 48px;
width: 56px; height: 56px;

/* 图标 */
size: 20px;
color: white;

/* 标签 */
font: Medium 12px; color: white;
```

### 输入框

```css
background: rgba(0,0,0,0.05);
border-radius: 48px;
padding: 16px 16px 16px 24px;
flex: 1;

/* 占位符 */
font: Regular 14px; color: rgba(0,0,0,0.4);

/* 操作图标（+、🎙） */
size: 24px; color: black;
```

### Sheet 投影

```css
border-top: 1px solid #DDE5DE;
box-shadow: 0 0 32px rgba(0,0,0,0.08);
border-radius: 32px 32px 0 0;
padding: 20px;
```

## 活动环（Activity Ring）

参考 Apple Watch 活动环，呈现运动、消耗、连胜三项核心数据。

### 结构

- 同心圆环：3 层，从外向内——青绿（运动分钟）/ 橙红（消耗）/ 金黄（连胜）
- 中心：Emoji 图标（带小型颜色角标）
- 环下数据条：三列，每列「数值 + 单位」+「指标名」

### 数据条规格

```css
/* 指标图标 */
size: 28px; border-radius: 50%;
/* 颜色跟随指标分类 */

/* 数值 */
font: Bold 20px;

/* 单位 */
font: Medium 12px; color: rgba(0,0,0,0.6);

/* 指标名称 */
font: Medium 12px; color: rgba(0,0,0,0.6);
```

## Onboarding 页面

### 全屏暗色背景

```css
background: linear-gradient(270deg, #FF6A4B 0%, #6D51F4 50%, #0D9EAA 100%);
/* + 深色 radial 叠加层使内容可读 */
```

### 内容卡片（情绪选择区）

```css
background: rgba(0,0,0,0.35);  /* 半透明暗色 */
border-radius: 32px;
padding: 24px;
```

### 情绪展示文字

```css
font: Bold, approx 56–72px; color: white;
/* 使用视觉重心在中上方 */
```

### 滑块（Slider）

白色圆形 thumb，轨道为半透明深色胶囊。

### 底部按钮

```css
/* 主 CTA —— 下一步 */

border-radius: 32px;
height: 60px;
font: Bold 20px; color: white;

/* 次要操作 —— 跳过 */
font: Regular 15px; color: rgba(255,255,255,0.6);
```

### 选项列表（暗色模式）

```css
/* 选项行 */
background: rgba(255,255,255,0.1);
border-radius: 32px;
padding: 14px 20px;

/* Emoji 图标 */
size: 32px;

/* 文字 */
font: Bold 18px; color: white;
```

## 登录 / 注册页

### 结构特征

- 背景：纯白（或浅灰 overlay 当 sheet 弹出时）
- 文字主体下沉至屏幕 1/2 以下，大量留白上方
- 品牌名竖向排列（欢迎使用 / Health Agent）

```css
/* 品牌标题（中文） */
font: Bold 40px; color: black;

/* 品牌标题（英文） */
font: Bold 40px, sf-pro; color: black;

/* 英文 tagline */
font: Monospace 14px; color: rgba(0,0,0,0.4);
/* "Physical AI Coaching Engine_" */
```

### CTA 按钮规格

```css
/* 主按钮（Apple ID / 手机登录） */
background: black;
border-radius: 32px;
height: 56px;
font: Bold 16px; color: white;

/* 次要按钮 */
background: rgba(0,0,0,0.08);
/* 同样规格 */
```

## 图标系统

使用自定义线性图标集，风格为 **1.5px stroke，24×24px，圆形线帽**。

常用图标语义：

| 图标名 | 用途 |
|---|---|
| `IconChevron` | 展开/折叠，导航 |
| `IconPoint` | 地理位置，户外运动 |
| `IconSun` | 晨间事件（早晨起床） |
| `IconCalenderSparkle` | AI 日历规划节点 |
| `IconAdd` | 新增操作 |
| `IconVoice` | 语音输入 |
| `IconClaw` | 品牌 Logo 图标（技能 Dock 专用） |
| `IconSparklesThree` | AI 分析 / Todo 完成状态 |
| `IconCheck` | 完成打勾 |
| `IconFire` | 减脂类别 |
| `IconBecepsRightArm` | 力量训练类别 |

辅助 Emoji 集（来自 Figma 文件 icon section）：健身、食物、奖励类 emoji 用于 Timeline 节点和计划条目配图。
