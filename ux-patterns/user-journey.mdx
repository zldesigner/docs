# 用户旅程地图

## 旅程概览

```
阶段一          阶段二          阶段三          阶段四
首次体验  →  习惯建立期  →  进阶成长期  →  长期伙伴期
（第1天）     （第2-30天）    （第1-6个月）    （6个月以上）
```

每个阶段用户有不同的心理状态、核心需求和潜在阻力，Agent 的策略也应相应调整。

---

## 阶段一：首次体验（第1天）

### 用户心理状态

```
好奇        期待        一点点不确定
"这跟其他健身App有什么不同？"
"它真的能帮到我吗？"
"会不会很复杂，用不下去？"
```

### 关键体验时刻

<Steps>
  <Step title="首次打开 — 定下第一印象">
    **目标：** 在30秒内让用户感到"这里有人懂我"

    ```
    ❌ 传统 App 式开场：
    请完成以下信息填写
    姓名：___
    年龄：___
    身高：___
    体重：___
    运动目标：[下拉选择]
    ...（还有10个字段）

    ✅ Agent 式开场：
    Agent：你好！我是你的健康伙伴。
           在我们开始之前，我只想问你一个问题：

           你今天选择打开这个应用，是因为什么？
    
    用户：想减肥
    
    Agent：减肥，好。很多人都是这样开始的。
           我想先了解一下你——不是你的体重数字，
           而是你。
           
           你以前尝试过减肥吗？
    ```

    **设计关键：** 第一个问题不问数据，问故事。
  </Step>
  <Step title="首次目标设定 — 建立信任">
    **目标：** 让用户感到"它真的在认真对待我的目标"

    在目标设定对话结束时，Agent 应该做一个"汇总确认"，展示对用户的完整理解：

    ```
    Agent：好，让我总结一下我对你的了解：

           👤 你的画像
           - 28岁，工作繁忙，每天坐着时间较长
           - 过去有过几次"开始健身"的尝试，都没有坚持超过2个月
           - 主要原因：计划太难、生活太忙
           
           🎯 你的目标
           - 6个月内减重7公斤
           - 希望身材看起来更紧实
           - 不想每天花超过1小时在健身上
           
           💡 我的初步判断
           - 你的主要挑战不是意志力，而是找到能融入你生活的计划
           - 先从每周3次、每次30分钟开始，这个强度你大概率能坚持

           这个理解对吗？有什么我理解偏了的？
    ```
  </Step>
  <Step title="第一个行动 — 快速给到价值">
    **目标：** 让用户在第一天就体验到真实价值，而不是"明天才开始"

    ```
    Agent：今天是第一天，我们不做大计划，做一件小事：
           
           今天下班后，出门走20分钟。
           不用跑，不用特别快，就走。
           
           这不是训练，这是"我们开始了"的信号。
           
           完成后告诉我，我会基于你的状态定制明天的安排。
           
           几点下班？我到时候提醒你。
    ```
  </Step>
</Steps>

### 第一天的成功指标

- 完成基本信息收集（对话方式，非表单）
- 有明确的第一个行动（当天或明天）
- 用户对 Agent 有"这里跟别的地方不一样"的感受

## 阶段二：习惯建立期（第2-30天）

### 用户心理状态

```
Week 1: 新鲜感 + 动力充足
Week 2: 新鲜感消退，第一次想放弃
Week 3-4: 若成功坚持，开始看到变化；若失败，已经离开
```

### 核心任务：越过放弃的第14天

研究表明，新习惯最容易在第2周被放弃。Agent 需要在这个时期特别关注：

<Tabs>
  <Tab title="正常推进（完成率≥70%）">
    **Week 1 策略：** 保持轻量频繁的正向反馈

    每次完成训练 → 即时庆祝（具体化，不是通用鼓励）
    每3天 → 小结一下这几天的进展
    满7天 → 第一周完成纪念 + 下一步预告

    **Week 2-3 策略：** 引入更多 Skill 深度

    ```
    Agent（第8天）：你已经连续8天完成了计划！
                   
                   我发现你的训练时间一直在下午6点左右——
                   这是你的"黄金训练时段"吗？还是只是方便？
                   
                   （了解这个，我可以帮你更好地安排训练和饮食节奏）
    ```
  </Tab>
  <Tab title="危险预警（连续2天未完成）">
    **触发条件：** 连续2天未打卡，且未主动与 Agent 交流

    ```
    Agent（平和介入，不是催促）：
    "这两天没看到你，是发生什么事了吗？
     
     完全没关系，我只是想确认你还好。
     
     如果是太忙、身体不舒服，或者就是累了——
     都可以告诉我，我们一起想想怎么调整。"
    ```

    **关键：** 第一条消息不提计划，不提进度，只关心人。
  </Tab>
  <Tab title="脱轨后的重建">
    当用户已经中断超过5天：

    ```
    Agent：你已经有5天没有训练了，这很正常——
           打断比坚持容易，每个人都会有这样的时候。
           
           我不需要你解释原因（当然，如果你想说，我在）。
           
           我只想问：你现在想重新开始吗？
           
           如果是，我们今天从最简单的一步开始，
           不用回到之前的计划，就是一个全新的开始。
    ```

    重建计划要比原计划简单30%，给用户重建信心。
  </Tab>
</Tabs>

### 本阶段的关键旅程点

```
第1天  → 首次行动完成（小成功体验）
第3天  → 第一个"我不想运动"时刻，Agent 如何回应
第7天  → 第一周完成庆祝（重要里程碑）
第10天 → 首次出现身体感受变化（精力、睡眠改善）
第14天 → 最高流失风险点（新鲜感完全消退）
第21天 → 习惯开始自动化（每天到点就想运动）
第30天 → 第一个月完成，重大里程碑
```

## 阶段三：进阶成长期（第1-6个月）

### 用户心理状态

```
目标感增强，开始看到结果
更细致的需求（想优化训练效果、了解营养更多知识）
可能的焦虑点：平台期、进度比预期慢
```

### 深度功能渗透

在这个阶段，引导用户逐步激活更多 Skill 能力：

```
Month 1 末：饮食营养 Skill 激活
  "你的训练一直很稳定！下一步提升效果的关键是饮食。
   要开始记录一下饮食吗？哪怕只记3天，我就能给你很多洞察。"

Month 2 末：健康数据深度分析
  "你已经积累了8周的训练数据。我帮你做一个深度分析，
   看看哪些时候你表现最好，哪些因素影响了你的训练质量。"

Month 3 末：目标里程碑与升级
  "三个月了！我们来看看你离当初的目标还有多远，
   以及是不是需要调整一下目标和计划。"
```

### 平台期管理

平台期是这个阶段的核心挑战，需要专门的干预策略：

<AccordionGroup>
  <Accordion title="体重平台期（减脂用户）">
    **检测：** 7日均值体重变化 < 0.2kg，持续超过14天

    **Agent 策略：**
    1. 主动识别并命名（"你正在经历减重平台期，这是正常的"）
    2. 多维度分析（不只看体重，看体围、照片、力量进步）
    3. 提供突破方案（热量循环、运动变化、检查代谢适应）
    4. 调整期望值（平台期可能持续3-6周）
  </Accordion>
  <Accordion title="训练瓶颈期（增肌/体能用户）">
    **检测：** 关键动作重量连续4周无进步

    **Agent 策略：**
    1. 排查恢复因素（睡眠、营养、训练频率）
    2. 建议周期化调整（降强度周 → 恢复 → 突破）
    3. 引入新刺激（动作变化、训练方法）
    4. 提供"正常化"（力量进步本来就不是线性的）
  </Accordion>
</AccordionGroup>

## 阶段四：长期伙伴期（6个月以上）

### 用户心理状态

```
健康已经是生活的一部分
对 Agent 有真实的情感连接
需求升级：更个性化、更专业、更有挑战性
可能的风险：无聊感、习惯化带来的减少互动
```

### 长期留存策略

**1. 目标更新循环**

每6个月，主动发起"新目标设定对话"，让用户感到在不断成长而不是原地踏步：

```
Agent（6个月纪念日）：
"6个月前，你告诉我你想减重7公斤，'从来没坚持超过2个月'。

今天，你减重了6.2公斤，训练连续186天。

这不只是数字的变化——你证明了你能做到。

接下来，你想要什么？是保持现状，还是开启下一个目标？"
```

**2. 关系深度化**

随着时间积累，Agent 对用户的了解越来越深，对话应该体现这种积累：

```
❌ 总是从零开始：
"你平时偏向有氧训练还是力量训练？"

✅ 建立在历史之上：
"你一直很享受周六的长跑，但最近三周你把长跑换成了骑行——
 是户外跑步的天气太热了，还是你找到了新的爱好？"
```

**3. 主动挑战**

为长期用户引入新挑战，维持新鲜感：

```
定期（每2-3个月）推送挑战邀请：
"你已经是一个稳定的跑者了。
 下个月有没有兴趣尝试你的第一个5公里计时赛？
 不是正式比赛，就是你自己的PB挑战。"
```

## 旅程中的通用设计原则

### 情感账户管理

将 Agent 与用户的关系看作一个"情感账户"：

```
增加情感存款：
+ 在正确的时机给予认可
+ 在困难时提供真实的支持
+ 用数据讲述用户的成长故事
+ 记住并引用用户说过的话

减少情感存款：
- 无意义的打扰（没有价值的通知）
- 重复的、通用的建议（显示出不了解用户）
- 在用户脆弱时给数据分析（而不是先共情）
- 错误地引用用户数据（显示出不可靠）
```

### 关键旅程摩擦点清单

需要特别设计以减少摩擦的时刻：

| 摩擦点 | 用户感受 | 设计应对 |
|-------|---------|---------|
| 首次注册 | 表单太多，想放弃 | 对话式收集，最多5步 |
| 首次记录饮食 | 搜索食物太麻烦 | 语言描述 + 快速选择 |
| 计划第一次被打断 | 打破连续感，想放弃 | 灵活调整，不归零 |
| 看不到效果时 | 怀疑是否有意义 | 主动挖掘隐性进步 |
| 遇到不懂的术语 | 感到被排斥 | 即时解释，无需主动询问 |
| 手动输入数据 | 繁琐，容易放弃 | 自动化优先，手动作备选 |
