# 愿景与定位

## 产品愿景

> 让每一个普通人都拥有一位专属的健康顾问——懂你的身体，陪伴你的成长，在你需要的时刻给出恰到好处的建议。

运动健康 Agent 的目标不是替代专业教练或营养师，而是**填补专业服务与日常生活之间的鸿沟**。它是一个随时在线、无处不在、持续学习的健康伙伴。

### 用户核心诉求

| 诉求层次 | 具体需求 | Agent 的回应方式 |
|---------|---------|----------------|
| **功能层** | 知道该练什么、吃什么 | 提供个性化训练和饮食计划 |
| **情感层** | 在坚持时获得认可和鼓励 | 进度庆祝、里程碑反馈、适时激励 |
| **成长层** | 理解身体变化背后的规律 | 数据洞察、知识科普、趋势解读 |

## 核心价值主张

### 1. 个性化而非通用化

不存在一个适合所有人的训练计划。Agent 通过持续感知用户的身体状态、生活节奏和目标变化，动态调整建议内容。

```
用户今天告知工作压力大 → Agent 自动将今日训练强度调低，推荐舒缓型有氧
用户本周体重增加 → Agent 主动分析近期饮食和训练数据，给出综合解读
```

### 2. 主动而非被动

优秀的健康伙伴不只是回答问题，更会在合适的时机主动介入：

- 检测到用户连续三天未完成训练 → 主动询问并提供调整方案
- 发现用户蛋白质摄入持续不足 → 提醒并推荐简单补充方式
- 临近周期复盘节点 → 自动生成健康周报并发起对话

### 3. 连贯而非碎片化

Agent 记住用户的每一次对话、每一个数据变化、每一个里程碑，构建完整的用户健康画像，让每次交互都建立在历史积累之上。

## 与现有产品的差异

| 维度 | 传统健身 App | 内容平台 | 运动健康 Agent |
|------|------------|--------|--------------|
| 个性化程度 | 低（模板计划） | 极低（通用内容） | 高（动态调整） |
| 交互方式 | 操作界面 | 浏览消费 | 自然对话 |
| 主动性 | 被动等待 | 被动推送 | 主动感知介入 |
| 连贯性 | 数据孤岛 | 无状态 | 持续记忆积累 |
| 情感陪伴 | 无 | 弱 | 核心能力之一 |
