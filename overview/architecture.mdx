## 核心层详解

### Agent 核心层

Agent 核心层是整个产品的"大脑"，负责三件事：

<Steps>
  <Step title="意图理解">
    解析用户输入的自然语言，识别用户的真实意图。不只是关键词匹配，而是结合上下文、用户状态和历史行为进行综合判断。

    ```
    用户输入："今天感觉很累"
    意图识别：① 情绪表达（需要共情回应）
              ② 隐含信号（可能需要调整今日训练计划）
              ③ 数据触发（睡眠/压力数据关联分析）
    ```
  </Step>
  <Step title="Skill 调度">
    根据识别到的意图，决定调用哪个（或哪几个）Skill，以及调用的顺序和参数。支持：
    - **单 Skill 调用**：意图明确时直接路由
    - **多 Skill 协同**：复杂场景下组合多个 Skill
    - **延迟调度**：注册定时任务，在未来特定时刻触发 Skill
  </Step>
  <Step title="响应生成">
    将 Skill 的返回结果转化为自然、个性化的对话响应。根据用户的沟通风格偏好（简洁/详细/激励/专业）调整表达方式。
  </Step>
</Steps>

### Skill 层

每个 Skill 是一个**自治的能力单元**，具备以下标准接口：

```typescript
interface Skill {
  id: string;
  name: string;
  description: string;

  // Skill 的触发条件
  triggers: SkillTrigger[];

  // 主执行逻辑
  execute(context: SkillContext): Promise<SkillResult>;

  // 该 Skill 所需的用户权限/数据
  requiredPermissions: Permission[];
}

interface SkillContext {
  userId: string;
  userProfile: UserProfile;
  healthData: HealthData;
  conversationHistory: Message[];
  intent: ParsedIntent;
  parameters: Record<string, unknown>;
}
```

## Skill 调度机制

### 触发方式

| 触发类型 | 描述 | 示例 |
|---------|------|------|
| **显式触发** | 用户直接请求 | "帮我制定本周训练计划" |
| **意图触发** | 用户意图隐含对某 Skill 的需求 | "我想减脂" → 训练计划 + 饮食营养 |
| **数据触发** | 外部数据变化触发 | 体重连续下降 → 目标追踪 Skill 评估调整 |
| **定时触发** | 预设时间节点触发 | 每周日 → 周报生成 |
| **事件触发** | 特定行为事件触发 | 完成首次训练 → 里程碑庆祝 |

### 多 Skill 协同示例

当用户说"我想在3个月内减重10斤"，Agent 会协同调度多个 Skill：

```
用户输入 → 目标追踪 Skill（目标注册 + 拆解）
                    ↓
           训练计划 Skill（生成减脂训练方案）
                    ↓
           饮食营养 Skill（生成饮食热量目标）
                    ↓
           健康数据 Skill（设定基准指标，建立监测计划）
                    ↓
           综合输出（整合四个 Skill 的结果，生成完整的启动方案）
```

### 数据隐私原则

<Warning>
  所有用户健康数据均为敏感信息，设计和实现时需严格遵守以下原则：
  - 最小化收集：只收集 Skill 实际需要的数据
  - 明确授权：每类数据的收集和使用需用户明确同意
  - 本地优先：尽可能在设备端处理，减少云端传输
  - 可撤销：用户可随时删除任何历史数据
</Warning>
