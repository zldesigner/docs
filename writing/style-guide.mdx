## 核心原则

**简洁 · 准确 · 一致 · 友好**

通过规范的文案提升产品易用性，帮助用户建立信任感，获得顺畅愉快的使用体验。

---

## 一、基础规则

| 规则 | 正确 | 错误 |
|---|---|---|
| 产品名大写 | Keep | keep / KEEP |
| 称谓 | 你 | 您 |
| 动作词 | 登录 | 登陆 |
| 账户词 | 账号 | 帐号 |
| 中英/中数混排 | 快来 Keep 一下！ | 快来Keep一下！ |
| 中英/中数混排 | 已训练 1100 分钟。 | 已训练1100分钟。 |

### 专有名词写法

以下词汇必须使用固定大小写，不可随意变形：

```
iOS  Android  Java  Node.js  MySQL
UI  iPhone  iPad  MacBook Pro  iMac  HTML5
```

## 二、中文排版

### 2.1 引号

优先使用**直角引号**（「」『』），而非弯引号（""''）。

| 场景 | 写法 | 示例 |
|---|---|---|
| 常规引用 | 直角引号 | 你竟然喜欢「苹果表」？ |
| 引号内再引用 | 双直角引号 | 「你竟然喜欢『苹果表』？」 |
| 讽刺/反语 | 弯引号 | 我也很 "喜欢"「苹果表」哦。 |

### 2.2 省略号与破折号

- **省略号**：占两个汉字宽度，含六个点 `……`
  - ✅ 中国设计还有太长路要走……
  - ❌ 中国设计还有太长路要走…（三个点是错误的）

- **破折号**：占两个汉字宽度 `──`
  - 示例：中国设计还有太长路要走──加油罢。

### 2.3 行首行尾禁则

**不能出现在行首**：顿号、逗号、句号、结束引号「」、结束括号）

```
❌  排版时注意某些
    符号不能在行首
    ，别弄错了。

✅  排版时注意某些
    符号不能在行首，
    别弄错了。
```

**不能出现在行尾**：开始引号「、开始括号（、书名号《

```
❌  她对我们说：「
    这书太赞了。」

✅  她对我们说：
    「这书太赞了。」
```

## 三、西文排版

### 3.1 基础写法

- 句首字母大写，单词间留空格
- 示例：`Have a question?`

### 3.2 标点空格规则

| 规则 | 示例 |
|---|---|
| 点号后加一个空格 | `Hello everyone! Welcome to my blog.` |
| 度、百分号前不加空格 | `17°, 100%` |
| 货币、正负号后不加空格 | `$10, -23` |
| @ 符号、版权符号后加空格 | `@ Hindy, © Hindy`（邮件地址除外） |
| 括号、引号前后加空格，内部无空格 | `5.04 ounces (143 grams)` |

### 3.3 连字符与破折号

| 符号 | 用途 | 示例 |
|---|---|---|
| 连字符 `-` | 组合相关单词 | `Multi‑Touch`, `Jean-Jacques Rousseau` |
| 全角连接号 `—` | 文章中断、转折、说明 | `you'll see what a press can do — you'll feel it.` |

### 3.4 斜体用法

斜体适用于以下场景：
- 强调文中某个词或某句话
- 标记外来语或读者不熟悉的词汇
- 书名、剧名、美术作品题目

### 3.5 大小写

- **专有名词**使用固定大小写：`the White House`（不是 `the white house`）
- **标题**可全部大写：`JUST DO IT.`

## 四、中西文混排

### 4.1 空格规则

| 场景 | 正确 | 错误 |
|---|---|---|
| 中英文之间 | `iOS 是个不错的操作系统。` | `iOS是个不错的操作系统。` |
| 中文与数字之间 | `已经到了 12 月了啊。` | `已经到了12月了啊。` |
| 中文与链接之间 | `我觉得 知乎 这个网站很赞。` | `我觉得知乎这个网站很赞。` |

### 4.2 专有名词

- ✅ `我刚买了台 iPhone 6s。`
- ❌ `我刚买了台 iphone 6s。`

### 4.3 缩写

- ✅ `UI 设计师应该学点 HTML5。`
- ❌ `UI 设计师应该学点 H5。`（H5 不是正式缩写）

### 4.4 标点

**使用全角标点**，全角标点与英文/数字之间不加空格：

- ✅ `我刚买了台 iPhone，好开心！`
- ❌ `我刚买了台 iPhone ，好开心！`（逗号前有多余空格）

**完整英文句子内部使用半角标点**：

- ✅ 《阿甘正传》的「You never know what you're gonna get.」这句台词令我印象最深。
