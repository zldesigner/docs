# 运动健康 Agent UX 知识库

这是一个面向产品设计师、UX 研究员与开发者的综合知识库，系统梳理了**以 Skill 为核心的运动健康 AI Agent** 的产品体验设计方法、交互范式与设计规范。

## 什么是运动健康 Agent

运动健康 Agent 是一个以对话为主要界面、以 Skill 为能力单元、以用户健康目标为驱动核心的 AI 产品形态。它不是一个静态的工具，而是一个能够**感知用户状态、主动规划行动、持续学习调整**的智能伙伴。

## 四大核心 Skill

| Skill | 核心能力 | 触发场景 |
|-------|---------|---------|
| 🏋️ 训练计划 | 个性化运动方案生成与调整 | 用户设定健身目标时 |
| 🥗 饮食营养 | 膳食分析、食谱推荐、营养摄入追踪 | 用户记录饮食或询问营养问题时 |
| 📊 健康数据 | 穿戴设备数据分析、健康趋势洞察 | 同步设备数据或周期性复盘时 |
| 🎯 目标追踪 | 目标设定、进度激励、里程碑庆祝 | 贯穿用户整个使用周期 |
